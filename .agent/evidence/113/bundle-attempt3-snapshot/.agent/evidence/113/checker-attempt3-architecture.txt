The old architecture searched raw markup fragments and re-parsed isolated paragraphs.
A link in a non-rendered HTML comment therefore supplied a counterfeit routing and
bounded-paragraph proof. Paragraph-local parsing also lost multiline comment/fence/
HTML context. This attempt separates four operations: source visibility masking;
actual supported link-markup recognition; destination decoding; document-relative,
repo-contained exact-target resolution. It retains the approved contract/44controls.

Visibility masking preserves character boundaries and original blank-paragraph
indices, removes closed/unclosed HTML comments and fenced code, recognizes fences
with longer valid closers, excludes indented/tab code and exact-run inline code,
and handles backslash escape parity. It never decodes the whole document.

The defined supported subset consists of simple inline Markdown links in ordinary
paragraphs (including visible labels containing inline code), and closed visible
standalone HTML anchors with href/title attributes and ordinary text/em/strong/code
labels. Images, reference links, nested Markdown brackets, raw-HTML-mixed Markdown
paragraphs and unsupported HTML containers/attributes cannot supply acceptance proof.
HTML context persists across blank lines. Code/pre/script/style/raw HTML text and
attributes cannot become active Markdown. Entity-displayed or escaped tag text
cannot become an HTML anchor by premature unescape. Only actual identified href
values undergo HTML character-reference and URL-path decoding.

Link records retain original paragraph identities. Both full-document routing and
bounded-paragraph selection use the same whole-document records. A comment/fence/
HTML wrapper spanning paragraphs remains non-rendered during bounded selection.
The one M11 crosslink must be a standalone added paragraph inside actual Section1;
a correct link relocated to Section2 cannot satisfy routing or bounded delta.
Destinations still resolve relative to the owning document, remain inside the repo,
and exactly name the contracted existing file; path spelling alone proves nothing.
